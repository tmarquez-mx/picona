- Picona es una extensión de Google Chrome para hacer memos a partir de navegación de páginas (i.e. prensa; videos; blogs, etc.) y vincularlos entre spi con ayuda de la IA. Los memos registran el URL de la página que le dió origen, la fecha, sugiere título y palabras clave, el tipo, etc.  Proporciona  varios formatos de exportación de modo que puedes seguir trabajándolos como una una base de conocimientos por ejemplo en Obsidian.
- Se realizó por videcoding usando Claude Sonnet 4.6 (gratis) y alguna horas(pocas) de Fable 5.
